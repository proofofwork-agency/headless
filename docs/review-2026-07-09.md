# Headless — Project Review, Rating, and Improvement Roadmap

Date: 2026-07-09. Method: four independent analysis streams — (1) full repo audit, (2) ContextRelay reference map (`../agenttalk/contextrelay`), (3) OpenCode plugin-API ground truth from the vendored clone (`opencode/`, anomalyco/opencode v1.17.17 @ 08096b5) plus a web ecosystem scan, and (4) an independent implementer's assessment by Codex via ContextRelay — reconciled by Claude (coordinator). Verified at review time: `bun run check` green (33 tests / 111 expects), `bun run build` green.

## Executive summary

Headless is a **credible, honestly-scoped MVP with a genuinely strong runtime spine** — the hash-chained ledger is ahead of even ContextRelay (the mature reference) on tamper-evidence — but its **most load-bearing safety claim (contained read-only execution) was the least backed by code** at review time, its OpenCode plugin could not actually be loaded by OpenCode as sited, and the package was not publishable. None of these are architectural flaws; all are addressable in small slices, and the reference implementations for the hard parts (worktree isolation, OS sandbox, env allowlisting, redaction) already exist in ContextRelay with near-zero external dependencies.

**Overall: 5.5/10 as reviewed — clearly a prototype, but one with an unusually solid core and a clear path to 8/10.**

## Key findings (ranked)

1. **[CRITICAL] Read-only is not contained for opencode.** `assertModeAllowed` only rejects `mode:"write"` on non-canWrite backends; a "read-only" opencode run gets the full-access default agent and full `process.env`. The containment recipe (OPENCODE_CONFIG_CONTENT tool/permission denies + env scrubbing + macOS sandbox) is described in this repo's own `docs/analysis-opencode.md` but was never ported. → Slice 1 (in progress).
2. **[HIGH] Plugin cannot load where it sits.** No `.opencode/plugin/` placement, no `opencode.json` `"plugin"` entry; npm path structurally broken. Fix is cheap; tool definitions themselves need no changes. → Slice 2.
3. **[HIGH] Publishability broken**; LICENSE was missing; no CI; no git history (fixed: baseline `6ebb939`). → Slice 5.
4. **[MED] Correctness batch:** silent `--model`/`--agent` drop (claude/codex); ledger unsigned-tail acceptance; `collectText` double-emit of string `content`; opencode parser dual-path double-collect; CLI arg foot-guns (`--model --json`, last-positional prompt, stack trace on bad backend); `deliberate` marks its handoff handled even when all workers fail; token overcounting (`total_tokens` summed with subsets). → Slice 3.
5. **[MED] O(n²) ledger appends** — full read+verify+rewrite per event; fine at MVP scale, degrades on long sessions.
6. **[LOW] Buffered-only output** — no live streaming; ContextRelay's `readline` line-reader idiom is the port target.

## Competitive positioning (ecosystem scan, mid-2026)

The OpenCode plugin ecosystem is mature and crowded (~150+ plugins; official ecosystem page + awesome-opencode). Multi-agent orchestration plugins already exist and are prominent: oh-my-openagent (OMO), OpenCode Ensemble, Mission Control, opencode-orchestrator, Open Conclave — most use git-worktree isolation and a shared task board, but **orchestrate OpenCode-only sub-agents**. Headless's defensible wedge is exactly its two non-negotiables:

- **Cross-backend execution** — one normalized runner over opencode / claude-code / codex / grok, which no prominent incumbent offers;
- **Tamper-evident native ledger** — hash-chained, verified-on-read audit trail; incumbents have dashboards, not auditability.

Conclusion: don't compete on orchestration UI; compete on *safe, auditable heterogeneous execution* — the "boring infrastructure" the orchestrators above could themselves build on.

## Reference assets (ContextRelay, ready to port)

All porting-relevant modules use only Node/Bun builtins. Ephemeral write-worktrees (`src/session/worktree.ts` + `git-helpers.ts`, fail-closed, diff capture, orphan sweep); macOS Seatbelt sandbox (`src/backup/os-sandbox.ts`, 148 LOC, probe-gated, self-contained); contained spawn + env credential allowlist (`src/backup/runner.ts`); opencode-as-worker deny recipe (`src/backup/opencode-adapter.ts`); redaction (`src/session/redaction.ts`, 41 LOC drop-in, 13 secret patterns); usage-control profiles; concurrency pool; kill-tree; SessionLock. Notably, ContextRelay's ledger has **no** hash chain — headless should keep its own chain and port redaction/compaction on top, not replace it.
